skillhub CLI 在 Windows Git Bash 下的使用（可复用）

  • 路径bug：直接运行 skillhub 命令会报错，因为 Git Bash 把 /c/Users/... 路径传给 Windows Python 时被错误解析成 d:\c\Users\...
  • 修复方法：用 MSYS_NO_PATHCONV=1 环境变量 + Windows 路径格式直接调 Python 脚本：
  MSYS_NO_PATHCONV=1 python3 "C:/Users/Administrator/.skillhub/skills_store_cli.py" --skip-self-upgrade search <关键词>
  MSYS_NO_PATHCONV=1 python3 "C:/Users/Administrator/.skillhub/skills_store_cli.py" --skip-self-upgrade --dir "C:/Users/Administrator/.workbuddy/skills" install <slug>
  • --skip-self-upgrade 跳过启动时的自升级检查（避免额外网络请求）
  • --dir 指定安装目录，用户级skill装到 ~/.workbuddy/skills/

安装结果

  • skill: psychological-counselor（心理疏导师）v1.0.0
  • 安装路径：C:\Users\Administrator\.workbuddy\skills\psychological-counselor\
  • 来源：SkillHub 远程仓库（lightmake.site API）

安全审查（手动，P2=安全）

  • 6个文件：SKILL.md / generate_report.py / config.json / manifest.json / .metadata.json / README.md
  • generate_report.py：仅import docx+datetime，无网络请求、无文件破坏、无subprocess、无eval/exec，只生成本地Word文档。第203行有引号嵌套语法bug（不影响安全）
  • SKILL.md：纯心理学疏导框架文本（感知-拆解-疏导-修复-巩固五步法），无prompt注入、无系统提示词篡改
  • 其余文件为纯JSON元数据/README
  • 结论：无恶意代码、无prompt投毒、无数据外泄，安全可用

skill 内容概要

  • 五步法：感知（心理状态界定）→ 拆解（根源挖掘）→ 疏导（情绪释放）→ 修复（平衡重建）→ 巩固（预防韧性）

therapy-board 首次实战：来访者关系困扰分析

来访者材料概要

  • 女性，大学生，从小由爷爷奶奶带大，与父母疏离
  • 父母每次给生活费时指责"只在要钱时才找我们"→ 来访者不想见父母
  • 决定毕业后不跟父母联系
  • 刚发现男友网络聊骚出轨 → 分手
  • 暑假无处可去，想回前男友身边"假期后再分手"
  • 核心情绪：孤单、被遗弃感（"父母不爱，男朋友背叛"）

阵容选择（5位）

萨提亚（家庭沟通模式）+ 罗杰斯（无条件积极关注缺失）+ 阿德勒（虚构目的论/自卑-补偿）+ 亚隆（存在性孤独）+ 弗兰克尔（态度选择自由）

核心发现

  1. "回前男友再分手"和"毕业后不联系"服务于同一目的：逃避"独自面对存在"的恐惧 [阿德勒]
  2. 从未体验过无条件积极关注，核心自我概念="我不值得被爱" [罗杰斯]
  3. 父母指责型沟通背后是掩埋的愧疚——双方都在用让对方更痛的方式呼喊爱 [萨提亚]
  4. "父母不爱，男朋友背叛"= 两次"被留下"验证了存在性孤独 [亚隆]
  5. 已承受最坏情况并活下来——生命力远超自我认知 [弗兰克尔]

5条跨流派共识

  1. "回前男友再分手"是核心危险信号——不解决会重复"因害怕孤独而留在不好的关系里"
  2. 核心创伤不是"父母对她不好"，而是"从未被无条件地看见"
  3. "毕业后不联系"本身不是问题，做决定的内在状态（恐惧驱动vs力量驱动）才是
  4. 来访者严重低估自己的心理韧性
  5. 当务之急不是修复关系，而是建立与自己之间的关系

关系动力学核心

存在性孤独（"我终究是一个人"）→ 核心恐惧（"没有人会真正留下"）→ 两种应对策略：切断过去（不联系父母）+ 延迟未来（假期后再分手）→ 唯独不面对当下（"我一个人能活下去吗？"）
