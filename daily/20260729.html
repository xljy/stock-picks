盘中承接扫描器 (intraday_scan.py) — 已完成

用户需求：在早盘报告后，盘中用一条命令扫出"当前符合承接形态"的票，耗时短。

实现

  • 新建 D:\WorkBuddy\Claw\intraday_scan.py
  • 读最新 intraday_watchlist_YYYYMMDD.json(观察池, 252只) + 腾讯批量实时行情(一次HTTP拉全部, 秒级)
  • 承接形态评分(0-100, 纯快照字段):
  • 分时均价线VWAP=成交额/成交量, 价≥VWAP +25
  • 量比≥1.5 +20 / ≥1.2 +14
  • 涨跌幅-3%~+7% +20 (排除已涨停锁定/跌停/崩盘<-5%)
  • 开盘不崩(open≥昨收*0.97) +10
  • 板块联动(同行业观察池内≥2只上涨) +15
  • 维持日内高位(价≥(高+低)/2) +10
  • --append-to <file> 自动识别 .html/.md: HTML包成<section>插到</body>前; MD追加表格段
  • 输出: 控制台表 + intraday_scan_YYYYMMDD_HHMMSS.json

关键事实

  • 09:18盘前腾讯接口只返昨收涨跌停快照(量=0, 量比=0, VWAP算不出), 故盘前0命中=正确行为; 开盘后(09:30-15:00)才生效
  • 实时行情默认腾讯批量接口(零配置); 用户原话"tdx实时行情", 但tdx是MCP不可在独立脚本调用, 已在代码注释标注替换点

盘中命令

  • 扫描: python D:/WorkBuddy/Claw/intraday_scan.py
  • 挂到早盘报告后: python D:/WorkBuddy/Claw/intraday_scan.py --append-to "C:/Users/Administrator/WorkBuddy/2026-06-10-22-32-06/dist/index.html"
