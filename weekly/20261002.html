二、本周思维方法进展

  1. "涨停家数 + 低炸板率"会骗人，必须叠看涨停股资金流：09-28、09-30 连续两天出现涨停但 net 大额净流出（丽珠 -4.04 亿、会稽山 -3.01 亿、康希诺 -3.56 亿、古越龙山 -5.24 亿），涨停标签在退潮期是派发工具。
  2. 宽度单日大幅收敛是修复夭折的领先信号，位移快于涨停家数变化（09-30 收敛 16pct 时涨停仍有 52 家）。
  3. 判别反弹质地要"三看"：宽度 + 连板高度 + 量能，缺一即弱反弹（09-29 三者缺其二）。
  4. 退潮后第一波反弹的资金去向是"最弱方向"而非"昨日主线"，用昨日强势主线预判反弹方向系统性失效（本周验证两次）。
  5. "炸板率低=健康"在退潮加速段失效，改用更硬的恐慌指标：跌停/涨停比、宽度是否跌破 20%。
  6. 指数分化幅度是情绪真伪的放大器：09-30 上证被银行/白酒托红，深成/创业板翻绿，单看上证会误判"市场偏强"。
  7. 回测侧——修因子前先验单位与边界：pctmin() 下午时段公式错位导致首封/末封时间类因子全部失真（首封>14:00 永为空集），且旧二波报告用同一个坏函数。结论偏差来自工具而非市场。
  8. 评分卡的约束不能过严："严格 4 档单调"把 1483/1492 样本挤进最低档，改「极差 ≥8pct + 样本 5 等分」后区分度才出现（D1 14.1% → D5 54.5%）。
  9. 二板进三板最可迁移的结论：T+1 是否跌破 T 日收盘是全样本最强分水岭（守住 73.7% vs 破过 8.2%）；两段式联合中"T 日强 + 低开"仅 8.8% —— T 日的强弱救不了低开的次日；位置类因子与二板家数基本无效（后者系数为负）。
  10. 选股池的构造方式决定结论，不是市场本身：主板占涨停 89%、连板梯队 100% 在主板，而 10 日涨幅前 60 主板 0 只 —— 所谓"创科更肥"是池子结构造成的假象（一进二 14.2% vs 5.0%，次日一字率反而更低 7.4% vs 16.9%）。
  11. 自动化会话拿不到连接器类 MCP 是设计行为（strict-mcp-config），不是鉴权故障；必须区分"未注入 / 真故障 / 健康"三态。根因换了以后，旧报告的措辞会被误当成现状。
  12. 跨源补缺先做归一化，且"补空"不等于"覆盖"：同花顺 reason_type 用 + 分隔、limit_up_type 用半角 T，不做归一会让题材聚类静默退化；而东财的"几天几板"比同花顺更贴 TDX，覆盖反而丢信息。
  13. 两套涨停原因标签一致率 0%（同花顺偏基本面/股东属性，TDX 偏行业/概念），交互式与自动化产出不可混称，须靠 source 字段标注来源。
  14. 呈现层教训（可迁移）：md 类走 render_md_page 不过 enhance_html，统一增强必须两条路径都接；验收不能只看"容器在不在"，要量 getComputedStyle().overflowX 与 documentElement.scrollWidth；<meta viewport> 存在 ≠ 手机端适配。

三、仍存在的主要盲区

  1. 资金口径断裂：三日 main_net（通达信主力）全缺，只能用同花顺全单 net，与既有 1 亿 / 5000 万主力阈值不可比。本周两个最硬的结论（涨停≠资金留场）都建立在这个弱口径上。
  2. 节假日前后无连续序列：10-01、10-02 无复盘记录，本周实际交易日仅 3 天且全为盘后单点，缺少盘中情绪演化路径，跨周对比样本量不足。
  3. 回测结论的时效边界不清：首封时间因子本周刚修完 bug，旧二波报告未回溯重跑，当前引用哪些已修正、哪些仍带偏差，未标注。
  4. 位置类因子系统性失效未被解释：首板/二板面板里市值、涨幅位置、大盘环境等因子基本无效，目前只有"无效"的事实，没有"为什么"。
  5. LEGACY 12 页含真实持仓明细仍可公网直链（仅撤首页入口），arb 表格 HTML 标签裸露（3 份）两项未裁定，长期挂着。
  6. 退潮期的定量阈值未成型：跌停/涨停比、宽度 20% 线目前是经验值，没有回测支撑。

五、改进建议

  1. 把每日复盘的 8 个必录字段固化成一张跨周序列表（成交额 / 宽度 / 涨停 / 跌停 / 炸板率 / 最高板 / 连板家数 / 当日主线），并与资金口径并列标注。本周三天全部结论都靠这几个数的相对变化得出，但现在它们散在各日志里、每次写周报要重新摘录，节前节后断档时尤其容易失真。
  2. 给同花顺 net 口径单独标定一份阈值，作为 main_net 缺失时的替代标准。自动化会话 TDX 未注入已成常态，资金判断长期挂在不可比口径上，等于每周都在重复同一个盲区。
  3. 给"已修正/未重跑"的回测结论加统一标注：pctmin() 修好后，引用旧二波报告的首封时间类结论时应显式标注"修正前口径"。否则下周、下下周继续引用时，没人分得清哪份结论带偏差。
